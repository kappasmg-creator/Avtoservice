# АвтоСервис — запись на ремонт и диагностика + справочник кодов OBD-II

Учебное приложение для автосервиса: клиенты записываются на обслуживание, оставляют рекомендации и жалобы,
а встроенная локальная база кодов OBD-II и симптомов помогает подобрать вероятные причины неисправности.

## Запуск

**Готовый exe (Windows):** запустите `AvtoServis.exe`. Откроется окно консоли и браузер с адресом
`http://127.0.0.1:8765`. Чтобы остановить программу, закройте окно консоли.
База данных `autoservice.db` создаётся рядом с exe при первом запуске.

**Из исходников:** нужен Python 3.10+ (сторонние библиотеки не требуются).

```
python app.py            # Windows: двойной щелчок по run_app.bat
python app.py --port 9000 --no-browser
```

**Собрать exe самостоятельно:** см. файл `КАК_ПОЛУЧИТЬ_EXE.txt` (на Windows через `build_exe.bat` или автосборка на GitHub, файл `.github/workflows/build-exe.yml`).
Скрипт установит PyInstaller и создаст `dist\AvtoServis.exe`.
(Windows-программу нельзя собрать на Linux/macOS: PyInstaller не поддерживает кросс-компиляцию.)

## Роли и вход

| Роль | Адрес входа | Возможности |
|------|-------------|-------------|
| Администратор | `/admin` | записи клиентов (статусы, комментарии), обращения (ответы), клиенты, учётные записи администраторов, редактирование базы кодов и симптомов |
| Клиент | `/login`, регистрация `/register` | запись на ремонт/диагностику, отмена записи, рекомендации и жалобы, справочник кодов, диагностика по кодам и симптомам |

**Первый вход администратора = регистрация.** Пока в системе нет ни одного администратора, страница `/admin`
показывает форму регистрации: введённые логин и пароль создают главного администратора.
Дальше новые администраторы создаются только из панели (раздел «Администраторы»).
Страницы входа клиента и администратора раздельные: администратор не может войти через клиентскую форму и наоборот.

## Состав проекта

| Файл | Назначение |
|------|-----------|
| `app.py` | HTTP-сервер, сессии, CSRF-защита, маршруты клиента и администратора |
| `db.py` | схема SQLite, пароли (PBKDF2-SHA256), пользователи, записи, поиск по справочнику |
| `diag.py` | подбор вероятных причин по кодам и симптомам |
| `views.py` | HTML-страницы и стили |
| `obd_data.py` | начальная база: 100+ кодов OBD-II и 20+ симптомов (можно редактировать в панели администратора) |
| `test_app.py` | сквозные тесты (`python test_app.py`) |
| `build_exe.bat`, `run_app.bat` | сборка exe и запуск |

## Как работает подбор причин

Это не нейросеть, а прозрачный экспертный алгоритм: причины из введённых кодов и отмеченных симптомов
получают баллы (код +2, симптом +2, совпадение по свободному тексту +1); причины, повторяющиеся у нескольких
источников, поднимаются выше. Результат — ориентир для диагностики, а не окончательный диагноз.

## Безопасность

Пароли хранятся только в виде хеша; формы защищены CSRF-токеном; SQL-запросы параметризованы; весь вывод
экранируется; cookie `HttpOnly`; число неудачных попыток входа ограничено; сервер слушает только `127.0.0.1`
и проверяет заголовок Host. Приложение рассчитано на локальное использование — для публикации в интернет нужны
HTTPS, внешний веб-сервер и дополнительная настройка.

## Ограничения

Справочник учебный. Генеральные коды (P0xxx, U0xxx) стандартизованы, но точная трактовка и методика проверки
зависят от марки и модели автомобиля — сверяйтесь с документацией производителя.
