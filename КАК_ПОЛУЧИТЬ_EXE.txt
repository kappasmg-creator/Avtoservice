КАК ПОЛУЧИТЬ AvtoServis.exe
===========================

Exe-файл для Windows можно собрать только на компьютере с Windows. Есть два способа.


СПОСОБ 1. На своём компьютере с Windows (5 минут)
--------------------------------------------------
1. Установите Python 3.10 или новее: https://www.python.org/downloads/
   ВАЖНО: на первом экране установщика поставьте галочку "Add python.exe to PATH".
2. Распакуйте архив с программой в любую папку (например, C:\AutoService).
3. Дважды щёлкните по файлу build_exe.bat.
   Он сам установит PyInstaller (нужен интернет) и соберёт программу.
4. Готовый файл появится здесь: dist\AvtoServis.exe
   Его можно скопировать куда угодно и запускать двойным щелчком, Python уже не нужен.

При первом запуске Windows может показать предупреждение SmartScreen
("Windows защитила ваш компьютер"). Нажмите "Подробнее" -> "Выполнить в любом случае":
программа не подписана цифровой подписью, но собрана из открытых исходников.
Антивирус иногда реагирует на одиночные exe, собранные PyInstaller, - это ложное срабатывание.


СПОСОБ 2. Без установки Python: сборка на GitHub
-------------------------------------------------
1. Зарегистрируйтесь на https://github.com (бесплатно) и создайте новый репозиторий.
2. Загрузите в него все файлы из этого архива (кнопка "Add file" -> "Upload files"),
   включая папку .github (если её не видно после загрузки - см. подробную инструкцию в ответе, пункт про создание файла вручную).
3. Откройте вкладку Actions -> "Build AvtoServis.exe" -> Run workflow.
4. Через 2-3 минуты откройте завершённый запуск и скачайте файл AvtoServis-exe
   (внутри архива лежит AvtoServis.exe).


ЕСЛИ НИЧЕГО НЕ ХОЧЕТСЯ СОБИРАТЬ
-------------------------------
Программа работает и без exe: установите Python и запустите run_app.bat
(или командой: python app.py). Функции те же.


КАК ПОЛЬЗОВАТЬСЯ
----------------
После запуска откроется браузер с адресом http://127.0.0.1:8765
Окно консоли не закрывайте - пока оно открыто, программа работает.
Администратор: страница /admin, первый вход = регистрация главного администратора.
База данных autoservice.db создаётся рядом с программой.
